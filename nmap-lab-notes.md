# Nmap – Cybersecurity Lab Notes

## Introduction
Nmap stands for Network Mapper. It is an open-source tool used for network discovery and security auditing.

## Main Uses
- Discover active hosts on an authorized network.
- Identify open network ports.
- Detect services running on systems.
- Help administrators understand network security.

## Important Concepts

- **Host Discovery:** Identifies devices that are reachable on a network.
- **Port Scanning:** Checks the state of network ports.
- **Service Detection:** Helps identify services running on open ports.
- **Security Auditing:** Helps administrators identify potential security weaknesses.

## Responsible Usage
Nmap should only be used on systems and networks where permission has been granted.
