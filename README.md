# Cybersecurity Lab Portfolio

## About This Repository
This repository contains my practical work, lab exercises, and learning notes from my Cybersecurity course at Air University, Islamabad.

## Purpose
The purpose of this portfolio is to document my cybersecurity learning, demonstrate practical skills, and maintain a record of my coursework.

## Repository Contents

- **git-commands.md:** Common Git commands with explanations and examples.
- **nmap-lab-notes.md:** Notes about Nmap and network scanning concepts.
- **system-info.sh:** A Bash script that displays basic system information.
- **.gitignore:** Specifies files and patterns that Git should ignore.

## Skills Demonstrated
- Linux command-line basics
- Git and GitHub version control
- Bash scripting
- Network security fundamentals
- Technical documentation
