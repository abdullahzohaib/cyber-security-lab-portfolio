# Git Commands – Cybersecurity Lab

## Introduction
Git is a version control system used to track changes in files and collaborate on projects.

## Common Git Commands

| Command | Purpose |
|---|---|
| git init | Initialize a Git repository |
| git clone | Copy a remote repository |
| git status | Check repository status |
| git add | Stage changes |
| git commit | Save changes in Git history |
| git push | Upload commits to GitHub |
| git pull | Download remote changes |
| git log | View commit history |
| git branch | List branches |

## Git Workflow
1. Create or edit project files.
2. Use git status to check changes.
3. Use git add to stage files.
4. Use git commit to save changes.
5. Use git push to upload changes to GitHub.

## Security Reminder
Never commit passwords, API keys, access tokens, or private information.
